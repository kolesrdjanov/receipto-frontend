# UI/UX Audit — receipto-frontend (Glass design system)

**Date:** 2026-06-24 · **Branch:** `feature/v2` · **Scope:** whole-app sweep
**Dimensions:** accessibility · responsive/layout · visual consistency · interaction/animation
**Method:** 5 parallel page-cluster audits + shell/token audit, then manual verification of the highest-impact claims against actual source. Standards: WCAG AA, Apple HIG, Material Design (via UI/UX Pro Max guidelines).

> Claims that were checked against real token values / line numbers are marked ✅ verified.
> A few sub-agent findings were **disproven on verification** and dropped (see the "Corrected / dropped" section) — don't re-add them.

---

## Themes (fix the pattern once, not 30 times)

Most findings collapse into **4 systemic patterns**. Fixing these in shared primitives clears the bulk of the list:

| # | Pattern | Where it lives | Affected screens |
|---|---------|----------------|------------------|
| **A** | **Icon-only action buttons are 32–36px** (`size-8`/`size-9`), below the 44px touch minimum | row kebabs, table action buttons, dialog close, scanner close, settle avatars | receipts, recurring, warranties, categories, loyalty, admin, groups, glass-dialog |
| **B** | **Status/trend/urgency conveyed by color alone** (no icon **and** no text fallback) | TrendPill, status badges, price-trend, "Best price", per-member hues | dashboard, receipts, recurring, items, groups |
| **C** | **Custom progress bars & charts have no ARIA** (`role=progressbar`/`aria-valuenow`; charts lack `role=img`+label or data-table alt) | budget meter, rank ribbon, coverage bar, recharts, SVG sparkline | dashboard, warranties, items |
| **D** | **Color swatch / toggle buttons use `outline-none` with scale-only focus** — invisible to keyboard | category & loyalty color pickers, some custom switches | categories, loyalty, groups, settings |

## CRITICAL — fix before merge

1. **`text-dark` is an undefined class on unselected rating stars** ✅
   `src/components/settings/primitives.tsx:226` — `n <= shown ? 'fill-warning text-warning' : 'text-dark'`. `text-dark` is not a Tailwind/Glass token (confirmed: zero token definition), so unselected stars fall back to `currentColor` and render an arbitrary inherited color. **Fix:** replace with `text-muted-foreground` (or a `text-fg-faint` if intentionally dim).

2. **`--fg-faint` fails body-text contrast in light mode** ✅
   `src/index.css:140` — `--fg-faint: oklch(0.7 0.008 260)` ≈ #a3a3a3 on white = **~2.3:1** (WCAG AA needs 4.5:1). Acceptable only for non-essential decoration; **not** for any readable label/value. **Fix:** darken to ~`oklch(0.58 …)` (≈4.5:1), or audit each `text-fg-faint` use and demote only truly decorative ones. Dark-mode twin `--fg-faint: oklch(0.5 …)` (line 202) is similarly weak (~2.8:1) — raise to ~0.6.

3. **Theme A — icon-only buttons below 44px** (touch + a11y). Representative sites:
   - `src/components/receipts/row-kebab.tsx` (`size-8`)
   - `src/components/recurring-expenses/primitives.tsx:198,225` (`size-8`)
   - `src/components/categories/primitives.tsx:178,196` & `src/components/loyalty-cards/primitives.tsx:146,168` (`size-8`)
   - `src/components/admin/users-table.tsx:375` (`size-8` Eye/Trash)
   - `src/components/glass/glass-dialog.tsx:142` (desktop close `size-8`)
   - `src/components/loyalty-cards/loyalty-card-scanner.tsx:145` (close `size-9`)
   - `src/components/groups/settlement-modal.tsx:93` (avatar picker)
   **Fix:** standardize an icon-button hit target ≥44px (e.g. `size-11` on mobile, or keep visual `size-8` but add `hitSlop`/invisible padding via a shared `IconButton`). Best done once as a shared variant.

4. **Theme B — color-only status/trend signaling.** Representative sites:
   - `src/components/dashboard/primitives.tsx:164` (TrendPill — ensure arrow icon always renders + `aria-label` w/ direction & %)
   - `src/pages/items/index.tsx:62` (price up/down = red/green, identical icon shape)
   - `src/components/items/store-comparison.tsx:91` ("Best price" = green only)
   - `src/components/recurring-expenses/primitives.tsx:25` (overdue/duesoon/upcoming)
   - `src/components/glass/primitives.tsx:29` (status badges)
   **Fix:** every functional color must pair with an icon **or** text. Use distinct glyphs for up vs down; add a check/star to "Best".

5. **Theme C — charts have no screen-reader path.**
   - `src/components/items/price-history-chart.tsx:163` (recharts SVG, no `role=img`/label/table)
   - `src/components/dashboard/focus/modules.tsx:349` (hand-rolled SVG sparkline)
   **Fix:** add `role="img"` + a summarizing `aria-label` to each chart container, and a visually-hidden data table for the underlying series. (WCAG: charts alone aren't accessible.)

6. **Theme D — color swatches have no visible focus ring** ✅ pattern
   `src/components/categories/primitives.tsx:94`, `src/components/loyalty-cards/primitives.tsx:48` — `outline-none` + scale-only feedback. **Fix:** add `focus-visible:ring-2 focus-visible:ring-ring` (keep scale as secondary).

7. **Loyalty code display hardcodes `bg-white`/dark text with no dark-mode path**
   `src/components/loyalty-cards/loyalty-card-display.tsx:44,50,67`. Intentional (barcodes must scan on bright white) — **but** the surrounding chrome should not punch a raw-white hole in dark theme. **Fix:** keep the code panel white (scanability) but give it an explicit framed container so it reads as deliberate, not a theming bug; confirm contrast of any overlaid text.

## HIGH

8. **Theme C — progress bars lack `role=progressbar`/`aria-valuenow`:** dashboard budget meter & rank ribbon (`src/components/dashboard/focus/modules.tsx:102,276`), warranty coverage bar (`src/components/warranties/primitives.tsx:106` → `src/components/ui/progress.tsx`). **Fix:** add the role + `aria-valuenow/min/max` + label, ideally in the shared `Progress`.

9. **Framer-driven animations bypass the global reduced-motion rule** ✅
   The CSS `@media (prefers-reduced-motion)` at `src/index.css:14` only kills CSS `animation`/`transition` — it does **not** stop Framer Motion (JS transforms). Verify these honor `useReducedMotion()`:
   - `src/components/onboarding/onboarding-modal.tsx:160` (slide-up sheet — render static when reduced)
   - `src/components/loyalty-cards/loyalty-card-scanner.tsx:168` (laser — hide or static crosshair when reduced)

10. **Form error/success alerts not announced to screen readers.**
    `src/components/glass/glass.tsx:166` (the shared Alert) renders without `role="alert"`/`aria-live`. Fixing the shared component covers auth OTP errors, form errors, etc. **Fix:** `role="alert" aria-live="assertive"` for errors, `aria-live="polite"` for success. Also auto-focus first invalid field on submit error.

11. **OTP verify button has no loading state** — `src/pages/auth/sign-in.tsx:188`. Email-submit uses `loading=`; verify does not, so during `verifyCode.isPending` the button looks idle and is double-clickable. **Fix:** `loading={verifyCode.isPending}`. Add a red-border/shake on cells when the code is wrong (`src/components/ui/input-otp.tsx`).

12. **Async actions not disabled during mutation** (double-submit risk): recurring "Mark paid" (`mark-paid-modal.tsx:86` — watches only RHF `isSubmitting`, not `markAsPaid.isPending`), warranty import/export (`src/pages/warranties/index.tsx:110`), receipts scan FAB (`src/pages/receipts/index.tsx:374` — add `aria-busy` too). **Fix:** drive `loading=` from the mutation's `isPending`.

13. **Sticky bars don't reserve top safe-area inset** (notch/Dynamic Island): `src/components/layout/page-toolbar.tsx:16` (`sticky top-0`), `src/components/receipts/expenses-mobile-header.tsx:56`. **Fix:** `top-[env(safe-area-inset-top)]` or pad the wrapper. (Confirm the AppLayout isn't already providing this before changing each site.)

14. **GlassDialog `max-h-[92vh]/[88vh]` uses `vh` not `dvh`** — `src/components/glass/glass-dialog.tsx:104`. On mobile this shifts when the URL bar shows/hides. **Fix:** `max-h-[92dvh]`.

15. **Admin Feature switches & clickable Pills lack `aria-label`** — `src/components/admin/primitives.tsx:83,146`. Icon-only/visual-only controls announce as bare "button"/"switch". **Fix:** pass `aria-label={title}` through `FeatureSwitchRow`/`Pill`.

16. **`opacity-60` for paused/ended rows drops contrast below 3:1** — `src/components/recurring-expenses/primitives.tsx:151`. **Fix:** use `text-muted-foreground` for the dim state instead of blanket opacity (opacity also dims the background/borders).

17. **Warranty lightbox controls: keyboard + contrast gaps** — `src/components/warranties/warranty-gallery-modal.tsx`: nav buttons rely on `title` not `aria-label` (line 159); `disabled:opacity-40` on `text-white/10` ≈ 2.4:1 (line 112); thumbnails `size-[42px]` < 44px (line 189). **Fix:** real `aria-label`s, `disabled:opacity-60`, bump thumbnails to 48px; confirm Esc closes (Radix should, verify).

## MEDIUM

18. **`mobile-tab-bar` NavLinks have no `focus-visible` ring** — `src/components/layout/mobile-tab-bar.tsx:19`. Keyboard tab-through is invisible. Add a focus ring.

19. **FAB negative margin overlaps neighbor tab hit-areas** — `src/components/layout/mobile-tab-bar.tsx:71` (`-mt-[26px]` on a `size-[54px]` FAB). Risk of mis-taps on the two adjacent tabs. **Fix:** raise tab-bar min-height or restructure so the FAB doesn't overlap sibling hit zones.

20. **Filter chips ~36px tall** — `src/components/receipts/filter-rail.tsx:95`. Below 44px on mobile. Bump `py` on small screens.

21. **Store-comparison "table" is a div grid with no `role=table`/columnheaders** — `src/components/items/store-comparison.tsx:130`. Screen readers read it as flat text. **Fix:** real `<table>` or ARIA grid roles.

22. **PageToolbar truncates long titles with no `title=`/tooltip** — `src/components/layout/page-toolbar.tsx:22`. Add a native `title` attr for the full string.

23. **Category reassign-on-delete preview circles are tiny (~20px, 11px emoji, 15% fill)** — `src/components/categories/category-delete-modal.tsx:64`. Hard to read. Reuse the larger `CategoryCircle`.

24. **Color swatch `aria-label` is the raw hex** — `src/components/loyalty-cards/primitives.tsx:39`. "#3B82F6" is meaningless aurally. **Fix:** map to color names.

25. **Camera/avatar upload button: no `:active` tap feedback on mobile** — `src/components/settings/primitives.tsx:252` (hover-only). Add `active:scale-95`.

26. **`--muted-foreground` is borderline** ✅ — `oklch(0.556 0 0)` ≈ #767676 on white ≈ **4.5:1** (passes for normal, just barely; fails as "large-only" assumption is unsafe). Leave as-is for body, but don't use it on tinted/soft backgrounds without re-checking.

## Corrected / dropped on verification (do NOT re-add)

- ❌ "`--muted-foreground` is 2.7:1" — **false**, it's ~4.5:1 (#767676 on white). See #26.
- ❌ "`--fg-2` is 3.3:1, fails AA" — **false**, `oklch(0.45 …)` ≈ #5e5e5e on white ≈ ~6:1, passes.
- ❌ "announcement-banner / sidebar `animate-pulse` ignores reduced-motion" and "chart skeleton `animate-spin` ignores it" — **false**, the global `@media (prefers-reduced-motion)` rule at `index.css:14` neutralizes all CSS `animation`/`transition` via `!important`. (Only **Framer** animations are exempt — see #9.)
- ❌ Several "missing aria-label" findings where an `aria-label` was already present (e.g. dashboard eye-toggle, some kebabs) — those just need `aria-pressed`/`aria-busy` state, not a label. Re-scoped into #4/#12.

## Recommended order of attack

1. **Shared primitives first** (clears the most surface area): `IconButton` 44px target (Theme A), `Progress` ARIA (#8), glass `Alert` role/live (#10), focus rings on swatch/toggle (Theme D).
2. **Token fix:** `--fg-faint` light + dark (#2), `text-dark` → token (#1).
3. **Per-screen color-not-only** pass (Theme B / #4).
4. **Charts** ARIA + data-table alt (#5).
5. **Framer reduced-motion** + async-button-loading sweep (#9, #11, #12).
6. Mobile/safe-area + dvh polish (#13, #14, #18–20).
